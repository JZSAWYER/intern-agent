# Contributing to Intern Agent

Read [the contributor guide](docs/CONTRIBUTING.md) for owner/collaborator branches,
fork contributions, local checks and pull request review. For running the project
on your own machine, use [installation](docs/INSTALL.md).

The optional [collaboration skill](skills/collaborate-on-source/SKILL.md) supports
coding agents working on a contribution. Supply its SKILL.md as task reference;
its presence in a source tree or VSIX does not automatically activate an agent.
Repository rules and the user's requested scope still apply.

First-party source and contributions use the [MIT license](LICENSE). Contributors
must have the rights to submit their changes under MIT; see
[licensing and provenance](docs/LICENSING_PROVENANCE.md) for scope and dependency terms.
